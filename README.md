## 📖 Giới thiệu

**Conflux** là bot quản lý server Discord toàn diện, hội tụ mọi tính năng bạn cần vào một điểm duy nhất. Từ moderation, logging, welcome, ticket đến automod — tất cả đều được thiết kế để hoạt động mượt mà, ổn định và đẹp mắt.

> *"Mọi thứ đều có điểm hội tụ. Mọi thành viên, mọi tin nhắn, mọi sự kiện. Conflux là điểm đó."*

---

## ✨ Tính năng

### 🛡️ Moderation
- Kick / Ban / Unban với log đầy đủ
- Timeout / Mute tạm thời
- Hệ thống cảnh cáo (warn) thông minh
- Xoá tin nhắn hàng loạt

### 🎉 Welcome & Goodbye
- Welcome message tuỳ chỉnh với embed đẹp
- Auto-role khi member join
- Log member rời server

### 📋 Logging
- Log tin nhắn xoá/sửa
- Log thay đổi role, channel, nickname
- Log voice join/leave
- Lưu trữ có tổ chức

### 🎫 Tickets
- Tạo ticket chỉ với 1 lệnh
- Phân loại theo chủ đề
- Transcript khi đóng
- Staff nhận thông báo tự động

### 🤖 AutoMod
- Chống spam tin nhắn
- Chặn link độc hại
- Lọc từ khoá xấu
- Chống raid tự động

### 📊 Tiện ích
- `/userinfo` — thông tin thành viên
- `/serverinfo` — thông tin server
- `/conflux` — thông tin bot + ping
- `/help` — menu trợ giúp
